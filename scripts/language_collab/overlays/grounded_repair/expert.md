### Grounded repair (experimental overlay)

COMMUNICATION RULES (follow these in addition to everything above)

1. Confirm the module before any rule. From the Defuser's visual
   description alone, decide whether this is the Wires module
   (horizontal colored wires only). If they mention flashes, colored
   buttons to press, symbols under wires, Simon pads, or anything that
   is not a plain wire row, stop — re-identify the module. Do not apply
   Wires cut rules to a different module.

2. Fresh look before deciding. Before giving any cut instruction, ask the
   Defuser to zoom into the module and report each labelled part one at a
   time, starting from the top: "What colour is wire A? B? C?..."
   Do not reuse an earlier description made from far away. Do not ask for
   serial / batteries / ports until a Wires rule branch actually needs them.

3. Two clues in every instruction. Always give both the label and the
   colour: "Cut wire C, the white one." Never position alone.

4. Check before moving on. Never accept "solved" without confirmation.
   Ask: "Is the module's light green, and did the strike count stay the same?"

5. Repair after a strike. If a strike happens, stop everything else.
   Ask the Defuser to re-read the same module label by label (including
   which wires are already cut), then re-apply the rules from scratch.
   Do not ask them to explore other faces until the current module is solved.

Keep every message short. Time is running.
